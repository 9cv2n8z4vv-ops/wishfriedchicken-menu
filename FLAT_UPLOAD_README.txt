WISH FRIED CHICKEN — TEK KLASÖR GITHUB PAKETİ

Bu pakette GitHub'a yükleyeceğiniz TÜM dosyalar tek klasördedir.
app/, components/, lib/, public/ vb. klasörler ZIP içinde yoktur.

Nasıl çalışır?
- PACKED__...srcpack dosyaları gerçek proje dosyalarını içerir.
- Vercel `npm run build` çalıştırdığında restore-structure.cjs otomatik olarak
  Next.js'in ihtiyaç duyduğu app/, components/, lib/, public/ vb. klasörleri
  build ortamında yeniden oluşturur.
- GitHub'a yüklerken bu klasörde görünen HER ŞEYİ seçip yükleyin.
- PACKED__ dosyalarını silmeyin veya adlarını değiştirmeyin.
- structure-manifest.json ve restore-structure.cjs dosyalarını silmeyin.

Vercel tarafında Framework Preset: Next.js olarak bırakın.
